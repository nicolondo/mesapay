Conexión con MESAPAY

El token se genera en MESAPAY, en Configuración → Impresión. Se muestra una sola vez: copialo completo y pegalo acá.

Impresoras

Una por cada equipo físico: cocina, barra, caja. La IP se ve imprimiendo la página de configuración desde la propia impresora (suele ser mantener apretado FEED al encenderla). Puerto 9100 salvo que la impresora diga otro.

Se aplica al instante. No hace falta reiniciar el servicio ni el PC.
